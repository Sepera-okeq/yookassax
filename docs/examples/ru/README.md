Во всех примерах предполагается, что клиент уже создан:

```python
from yookassax import YooKassa

kassa = YooKassa(shop_id="123456", secret_key="live_...")
```

либо, для асинхронного режима:

```python
from yookassax import AsyncYooKassa

kassa = AsyncYooKassa(shop_id="123456", secret_key="live_...")
```

## Про билдеры

В официальном SDK у каждого запроса есть класс-билдер вида
`PaymentRequestBuilder`. Здесь их нет: тело запроса это обычный словарь.

Причина в том, что билдер повторяет структуру JSON, но отстаёт от неё. Когда
ЮKassa добавляет поле, словарь принимает его сразу, а билдер только после
обновления библиотеки. Собрать словарь по документации API проще, чем искать
подходящий сеттер.

Если нужна валидация до отправки, соберите свою модель на стороне приложения и
передайте `model_dump()`.
